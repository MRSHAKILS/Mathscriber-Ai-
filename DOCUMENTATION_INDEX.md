### Backend Structure

```
backend/
├── mathscriber_ai/    # Django project
│   └── settings.py    # Configuration
├── converter/         # Main app
│   ├── converter.py   # Gemini API
│   ├── views.py       # Endpoints
│   └── urls.py        # Routes
└── requirements.txt   # Dependencies
```

**Learn more:** [ARCHITECTURE.md](ARCHITECTURE.md#backend-architecture)

### Frontend Structure

```
frontend/
├── app/              # Pages
│   ├── page.tsx      # Home
│   ├── upload/       # Upload page
│   ├── scan/         # Canvas page
│   └── result/       # Results page
├── components/       # Components
└── lib/             # Utilities
```

**Learn more:** [ARCHITECTURE.md](ARCHITECTURE.md#component-hierarchy)

### Essential Commands

```bash
# Backend
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver

# Frontend
cd frontend
npm install
npm run dev
```

**Learn more:** [SETUP.md](SETUP.md#backend-setup)


## 🎯 Common Tasks

### Task: Add Gemini API Key

1. Get key from https://makersuite.google.com/app/apikey
2. Copy `backend/.env.example` to `backend/.env`
3. Add your key: `GEMINI_API_KEY=your_key_here`

**Reference:** [SETUP.md](SETUP.md#step-2-backend-setup)

### Task: Change UI Colors

1. Open `frontend/tailwind.config.js`
2. Modify colors in `theme.extend.colors`
3. Restart frontend server

**Reference:** [DEVELOPMENT.md](DEVELOPMENT.md#design-system)

### Task: Add New API Endpoint

1. Add view in `backend/converter/views.py`
2. Add serializer in `backend/converter/serializers.py`
3. Add URL in `backend/converter/urls.py`
4. Test with curl or Postman

**Reference:** [DEVELOPMENT.md](DEVELOPMENT.md#backend-architecture)

### Task: Add New Page

1. Create `frontend/app/newpage/page.tsx`
2. Add link in `frontend/components/Navbar.tsx`
3. Test navigation

**Reference:** [DEVELOPMENT.md](DEVELOPMENT.md#component-hierarchy)

### Task: Deploy Backend

1. Choose hosting (Heroku, Railway, etc.)
2. Set environment variables
3. Update settings for production
4. Deploy

**Reference:** [CHECKLIST.md](CHECKLIST.md#backend-deployment)
