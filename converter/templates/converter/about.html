About MathScriber

MathScriber is an AI-powered web application that transforms handwritten math, tables, and diagrams into perfect LaTeX code using multiple state-of-the-art AI models.

Features

  • 11 different AI models for optimal accuracy
  • Support for equations, tables, and diagrams
  • Real-time LaTeX preview with MathJax
  • Professional LaTeX editor with compilation
  • One-click export to Overleaf
  • Mobile-responsive design with dark mode

Technology Stack

  • Backend: Django 5.2.6
  • Frontend: Tailwind CSS 3.x + DaisyUI
  • AI Models: Gemini, Groq, Mistral, OpenAI, and more
  • Rendering: MathJax 3
